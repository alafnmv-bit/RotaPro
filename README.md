# RotaPro Entregas — versão preparada para Hostinger

Sistema full-stack para gestão de entregas com Node.js, Express, PostgreSQL, JWT, Socket.IO, GPS e OpenStreetMap.

## Recursos
- 131 localidades com taxas de entrega.
- Login e cadastro de entregadores.
- Perfil do entregador e chave Pix.
- Painel administrativo.
- Clientes salvos.
- Criação de pedidos e cálculo automático da taxa.
- Entregadores recebem novas entregas em tempo real.
- Aceite concorrente de entregas.
- Status de entrega.
- GPS do entregador durante entrega ativa.
- Mapa OpenStreetMap.
- Rotas pelo Google Maps.
