# RotaPro Entregas — arquivos separados

## Estrutura

- `public/index.html` — estrutura principal da interface
- `public/style.css` — todos os estilos CSS
- `public/app.js` — lógica do aplicativo no navegador
- `public/splash.png` — imagem de abertura
- `server.js` — servidor/API
- `db/schema.sql` — estrutura do banco PostgreSQL
- `db/seed.sql` — 131 localidades e respectivas taxas
- `package.json` — dependências e scripts
- `.env.example` — exemplo de configuração
- `Dockerfile` — imagem do servidor
- `docker-compose.yml` — ambiente local com PostgreSQL
- `README.md` — instruções do projeto

## Observação

O frontend agora está separado em HTML, CSS e JavaScript. O backend e os arquivos do banco já estavam separados e foram mantidos.
